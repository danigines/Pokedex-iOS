# Pokédex MVC

UIKit implementation of the Pokédex using Model–View–Controller.

## Status

The project is currently a clean application baseline. No Pokédex functionality has been implemented.

The implementation will keep view controllers focused on presentation and coordination while avoiding unnecessary abstractions and the Massive View Controller problem.

Code is organized by feature. Application lifecycle files live in `App`, reusable infrastructure will live in `Core`, and shared components will be introduced only when actual reuse exists.

## Run

Open `PokedexMVC.xcodeproj`, select `PokedexMVC`, and run it on an iOS simulator.

See the [architecture strategy](../../Documentation/Architecture-Strategy.md) and [feature parity matrix](../../Documentation/Feature-Parity.md).
