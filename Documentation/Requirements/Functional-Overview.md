# Functional Overview

The planned product is a UIKit Pokédex backed by PokéAPI. All architecture variants must provide equivalent behavior and appearance.

Planned capabilities include a Pokémon grid, search by name or ID, details and evolution navigation, favorites, recently viewed Pokémon, display preferences, appearance selection, caching, and related PokéAPI resources.

Features will be specified and implemented incrementally. This document describes future scope, not completed functionality.
